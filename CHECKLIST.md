# Open Dredmor - Implementation Checklist

This checklist tracks all functionality needed to go from the Godot 4 skeleton to a fully playable clean-room reimplementation of *Dungeons of Dredmor* using the user's local Dredmor installation assets.

Checklists are organized into rounds under `checklist/round-<N>/`.
